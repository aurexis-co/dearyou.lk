DEARYOU.LK — GITHUB PAGES UPLOAD INSTRUCTIONS

IMPORTANT: Extract this ZIP first. Upload the CONTENTS, not the ZIP and not the outer folder.

1. Open your GitHub repository: awanthap/dearyou.lk
2. Delete the old website files if they are still there.
3. Click Add file > Upload files.
4. Upload everything inside this package so index.html is visible at the repository root.
   The root must show: index.html, style.css, script.js, assets, and demos.
5. Commit the changes to the main branch.
6. Open Settings > Pages.
7. Under Build and deployment choose:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
8. Click Save and wait approximately 1–3 minutes.
9. Open: https://awanthap.github.io/dearyou.lk/

If GitHub shows 404, check that index.html is directly in the repository root—not inside another folder.
